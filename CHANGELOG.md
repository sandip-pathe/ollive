# Changelog

All notable changes to Ollive are recorded here. The project follows semantic
versioning for source tags while the `0.x` API and packet schema remain
experimental and may change between minor versions.

## [0.1.0] - 2026-07-11

### Added

- Canonical `AgentRun` JSON collector and first-party TypeScript SDK.
- Deterministic `agentic_insurance_v1` policy evaluation with optional BYOK AI
  review findings.
- Exportable risk evidence packets with provenance, failure nodes, owners, and
  remediation.
- Run-first Inspect dashboard, chat-as-agent example, and Markdown chat output.
- Local Docker Compose reference stack and OSS integration documentation.

### Release boundaries

- Experimental single-trust-domain reference implementation only.
- No npm publication, hosted Ollive dependency, production deployment profile,
  supported in-place migration path, certification, underwriting decision, or
  safety guarantee.
